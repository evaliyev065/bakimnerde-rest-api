# Bakımnerde REST API — İlerleme Kaydı

> **Güncelleme:** 22.07.2026 18:30 (UTC+3)  
> **Durum:** Bağımsız repository sınırına taşındı; mevcut davranış korunuyor

## Mimari

- Fiziksel kök artık `bakimnerde-workspace/bakimnerde-rest-api` konumudur.
- Repository'nin kendi `package.json`, lockfile, TypeScript config, `.env`, `.gitignore`, test ve Postman artefact'ları vardır.
- Modül-içi dikey mimari korunmuştur: `application`, gerektiğinde `domain`/`infrastructure`, `presentation`.
- `src/bootstrap/container.ts` composition root'tur; global service locator kullanılmaz.
- Yönetim paneli ve saha Mobile App kaynakları API repository'sine eklenmemiştir.

## Korunan davranış

- `GET /health-live`, `GET /health-ready`
- Standart JSON başarı/hata zarfları ve request ID
- Query ve nested URL reddi
- `PUT`, `PATCH`, `DELETE` için `405 API_METHOD_NOT_ALLOWED`
- Kaynak görünürlüklü `.env` yükleme ve secret içermeyen config logları

## Doğrulama

Taşıma sonrası `npm run typecheck`, 5 dosyada 22/22 otomatik test ve production build geçti. Taşınmış eski `dist` Windows ACL'si nedeniyle ilk build yazamadı; yalnız üretilmiş `dist` hedefi doğrulanarak silindi ve yeni repository kökünde başarıyla yeniden üretildi. Manuel testlerin önceki `GEÇTİ` işaretleri `bakimnerde-docs/docs/testing/MASTER_TEST_PLAN.md` içinde korunmuştur.

Production runtime smoke testinde `GET /health-live` → `200` ve request ID echo; `PATCH /health-live` → `405 API_METHOD_NOT_ALLOWED` ile `Allow: GET, POST` doğrulandı.
